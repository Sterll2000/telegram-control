# ТЗ — список админов и синхронизация Iris

## 1. Цель
В основном Telegram Control Mini App добавить вкладку «Список админов», а источником истины для назначений сделать ответы Iris из четырёх чатов: два чата группы «Черный чат» и два чата группы «Синий чат».

## 2. Группы и ранги
- ⚫ Черный чат
- 🔵 Синий чат

Ранги:
1. ⭐ Стажер — 1
2. ⭐⭐ Ст.стажер — 2
3. ⭐⭐⭐ Админ — 3
4. ⭐⭐⭐⭐ Гл Админ — 4
5. ⭐⭐⭐⭐⭐ Владелец — 5

## 3. Авторизация
Пользователь Mini App авторизуется через Telegram `initData`. Username, имя и Telegram ID берутся из подписанных Telegram-данных на сервере. Iris не является механизмом аутентификации.

## 4. Синхронизация
Монитор получает сообщения Iris, определяет группу по чату, парсит ранги и пользователей, после чего сохраняет snapshot. Snapshot'ы двух чатов одной группы объединяются по username.

- новый человек → создаётся/связывается с `users` и получает Iris assignment;
- существующий → обновляется ранг, звёзды и role;
- пропавший из объединённого snapshot → Iris assignment удаляется;
- обычный `users` не удаляется;
- ручное назначение (`MANUAL`) не удаляется автоматикой Iris;
- сервер является единственным местом, где применяются права.

## 5. Browser demo
В основном приложении `/api/admins` принимает POST для тестового snapshot. Это доступно только пользователю с `MANAGE_USERS`. В UI «Список админов» есть форма «Тест сообщения Iris».

## 6. Production monitor
Для production предусмотрены переменные `IRIS_API_ID`, `IRIS_API_HASH`, `IRIS_SESSION`, а также четыре chat id. Монитор должен работать отдельным long-running worker/process и вызывать серверный sync endpoint или общий сервис синхронизации. Bot API для чтения чужих сообщений не используется; нужен Telegram user/MTProto session с доступом к четырём чатам.
