Полный `npm run typecheck` / `npm run build` не выполнен, потому что npm не смог установить зависимости из-за сетевого таймаута. Это ограничение среды сборки, а не результат проверки исходников.

На локальной машине после распаковки обязательно выполнить:

```powershell
npm install --no-audit --no-fund
npm run typecheck
npm run build
npm run feature-smoke
```
